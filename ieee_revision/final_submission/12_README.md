# Final Five-Workload IEEE Submission Package

This directory contains the submission-ready rewrite based on the current validated repository evidence.

## Author-facing files

1. `01_MANUSCRIPT_FINAL.md` - clean final manuscript with figures, tables, and references.
2. `02_MANUSCRIPT_COPY_PASTE.txt` - direct-transfer copy for the IEEE template.
3. `03_RESPONSE_TO_REVIEWERS_FINAL.md` - rewritten response organized by reviewer comment.
4. `04_SUPPLEMENTARY_MATERIAL.md` - structured supplement.
5. `MANUSCRIPT_FINAL_CLEAN.md` - clean duplicate requested by the submission brief.
6. `MANUSCRIPT_FINAL_MARKED.md` - readable marked version identifying substantive revision classes.

## Internal validation files

- `05_CLAIM_AUDIT_FINAL.md`
- `06_REFERENCES_FINAL.md`
- `07_REFERENCE_AUDIT_FINAL.md`
- `08_FIGURE_CAPTIONS_FINAL.md`
- `09_TABLES_FINAL.md`
- `10_CHANGELOG_FROM_PRIOR_REVISION.md`
- `11_SUBMISSION_CHECKLIST.md`
- `evidence_manifest/`

## Figures

`figures/main/` contains seven main figures. `figures/supplementary/` contains four supplementary figures. Each figure is available as PDF, SVG, and 600-dpi PNG. Quantitative figures are regenerated by `scripts/generate_submission_figures.py` from `figure_data/`.

## Scientific boundary

The architecture results are Timeloop/Accelergy/CACTI model outputs. The link results are independent ngspice simulations of one representative path. No fabricated-silicon, post-layout, full-network, thermal-field, or sensing-accuracy result is claimed.

## Validation

Run:

```bash
python3 scripts/generate_submission_figures.py
python3 scripts/validate_submission.py
```

The validator recomputes reductions, checks paired cycles/utilization/MACs, verifies figure/data completeness, checks citations and cross-references, and scans for unsupported legacy phrases.
