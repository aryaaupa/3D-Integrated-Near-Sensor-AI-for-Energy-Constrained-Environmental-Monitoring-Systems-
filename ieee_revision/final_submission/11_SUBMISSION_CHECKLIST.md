# Submission Checklist

## Required upload set

- [ ] Revised clean manuscript transferred into the journal's IEEE template from `01_MANUSCRIPT_FINAL.md` or `02_MANUSCRIPT_COPY_PASTE.txt`.
- [ ] Response to reviewers: `03_RESPONSE_TO_REVIEWERS_FINAL.md`.
- [ ] Journal-required manuscript source files: **VERIFY IN JOURNAL SUBMISSION PORTAL**.
- [ ] Separate main figures if requested by the portal: use vector PDFs from `figures/main/`.
- [ ] Confirm author names, affiliations, corresponding-author details, ORCID identifiers, funding, conflicts, and acknowledgments before upload.
- [ ] Confirm manuscript ID and revision deadline in the portal.

## Marked revision

- [ ] Upload `MANUSCRIPT_FINAL_MARKED.md` only if the journal requests a marked manuscript.
- [ ] If the portal requires tracked Word/PDF changes, transfer the readable revision markers into the journal template; do not submit raw Git diffs.

## Optional / if portal allows

- [ ] Supplementary material: `04_SUPPLEMENTARY_MATERIAL.md` plus `figures/supplementary/`.
- [ ] Standalone figure captions: `08_FIGURE_CAPTIONS_FINAL.md`.
- [ ] Separate tables: `09_TABLES_FINAL.md`.

## Internal only - do not submit unless explicitly requested

- `05_CLAIM_AUDIT_FINAL.md`
- `07_REFERENCE_AUDIT_FINAL.md`
- `10_CHANGELOG_FROM_PRIOR_REVISION.md`
- `11_SUBMISSION_CHECKLIST.md`
- `12_README.md`
- `figure_data/`
- `scripts/`
- `evidence_manifest/`
- raw repository traceability, checksums, validator logs, and development notes

## Portal-dependent items

The current repository does not establish the portal's exact file requirements. Verify each item in the live submission portal rather than assuming:

- clean manuscript required: **VERIFY IN JOURNAL SUBMISSION PORTAL**;
- marked manuscript required: **VERIFY IN JOURNAL SUBMISSION PORTAL**;
- Word/LaTeX source required: **VERIFY IN JOURNAL SUBMISSION PORTAL**;
- figures uploaded separately: **VERIFY IN JOURNAL SUBMISSION PORTAL**;
- graphical abstract: **VERIFY IN JOURNAL SUBMISSION PORTAL**;
- highlights: **VERIFY IN JOURNAL SUBMISSION PORTAL**;
- supplementary file format/size: **VERIFY IN JOURNAL SUBMISSION PORTAL**.

## Final author checks

- [ ] Do not rename dense CONV2/4/5 as canonical AlexNet layers.
- [ ] Do not describe 160 fF as measured bump capacitance.
- [ ] Do not describe Timeloop cycles as improved or reduced.
- [ ] Do not combine 63.77% link energy with the architecture energy reductions.
- [ ] Do not add a sensing-accuracy-versus-temperature curve without a new sensor experiment.
- [ ] Check final IEEE-template pagination, column breaks, table width, and figure legibility.
- [ ] Confirm all references appear in the template bibliography and every in-text citation resolves.
