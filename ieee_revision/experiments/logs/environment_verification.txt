usage: accelergy [-h] [-o OUTDIR] [-e EXTRA_PLUGINS [EXTRA_PLUGINS ...]]
                 [-p PRECISION] [-v] [-f [OUTPUT_FILES ...]]
                 [--oprefix OPREFIX] [--suppress_version_errors]
                 [--update_config_version] [-l]
                 [files ...]

Accelergy is an architecture-level energy estimator for accelerator designs.
Accelergy allows users to describe the architecture of a design with user-
defined compound components and generates energy estimations according to the
workload-generated action counts.

positional arguments:
  files                 list of input files in arbitrary order.Accelergy
                        parses the top keys of the files to decide the type of
                        input the file describes, e.g., architecture
                        description, compound component class descriptions,
                        etc.

options:
  -h, --help            show this help message and exit
  -o OUTDIR, --outdir OUTDIR
                        Path to output directory that stores the ERT and/or
                        flattened_architecture and/or energy estimation.
                        Default is current directory.
  -e EXTRA_PLUGINS [EXTRA_PLUGINS ...], --extra_plugins EXTRA_PLUGINS [EXTRA_PLUGINS ...]
                        Paths to additional Accelergy plug-ins to be used for
                        energy/area estimation. Plug-ins must be defined using
                        the Python plug-in format.
  -p PRECISION, --precision PRECISION
                        Number of decimal points for generated energy values.
                        Default is 6.
  -v, --verbose         If set to 1, Accelergy outputs the verbose version of
                        the output files Default is 0
  -f [OUTPUT_FILES ...], --output_files [OUTPUT_FILES ...]
                        list that contains the desired output files. Options
                        include: ERT, ERT_summary, ART, ART_summary,
                        energy_estimation, flattened_arch, and all (which
                        refers to all possible outputs)
  --oprefix OPREFIX     prefix that will be added to the output files names.
  --suppress_version_errors
                        If set, Accelergy will not raise errors if the input
                        files are of incompatible versions. This may result in
                        unexpected behavior.
  --update_config_version
                        Update the Accelergy config file (usually
                        ~/.config/accelergy/accelergy_config.yaml) to the
                        latest version.
  -l, --list-components
                        List all supported components and actions.
